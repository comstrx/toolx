# panelx

## What is panelx?

**panelx** is an internal admin panel builder.

It allows the company to create powerful admin dashboards faster by describing what each panel needs, instead of building every screen manually from zero.

For example, the developer can create simple files like:

- `admin.js`
- `vendor.js`
- `delivery.js`
- `affiliate.js`

Each file describes one admin panel: tables, filters, forms, fields, images, statistics, permissions, and relations.

Then panelx can use this description to generate a full admin interface.

---

## Simple Example

Instead of manually building a full product management page, the developer writes a clear description of the product panel:

- What columns appear in the table
- What filters are available
- What fields appear in the form
- What images or files can be uploaded
- What statistics should be shown
- What related data should appear
