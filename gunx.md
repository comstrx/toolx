# ✨ Gunx

> **One command system for every project, every language, every workflow.**

---

## The Problem

The company works with many technologies — Laravel, Next.js, Python, Node, Rust, mobile, scripts.

Every stack has its own commands: different install, different test, different build, different release.

Developers waste time switching mental models. Each new project means re-learning the basics.

---

## The Solution

gunx is a unified project command center.

The developer always uses the same simple commands. gunx detects the project type and runs the right workflow underneath.

```bash
gunx install
gunx run
gunx test
gunx build
gunx release
```

One workflow. Every stack. Every project.

---

## Real Example

| Scenario | Before | After |
|----------|--------|-------|
| Laravel project | `composer install && php artisan ...` | `gunx install` |
| Next.js project | `npm install && next build ...` | `gunx install` |
| Rust project | `cargo check && cargo build ...` | `gunx install` |

The developer types the same command. gunx knows what to do.

---

## Business Impact

- **One workflow for everything** — developers stop relearning every project
- **Faster onboarding** — new hires productive across all stacks immediately
- **Better release control** — every project releases the same professional way
- **Quality enforced by default** — tests, checks, and audits run consistently
- **Scales across clients** — works no matter what stack the client uses
