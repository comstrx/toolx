## 2. Required Work Tools

### 2.1 Claude Max Subscription

- **Plan:** Claude Max — 5x usage plan
- **Cost:** **$100 per month** (~5,200 EGP)
- **Usage:** Primary AI assistant for development, code analysis, documentation writing, complex problem solving, and accelerating the development of the company's internal tools

### 2.2 ChatGPT Plus Subscription

- **Plan:** ChatGPT Plus
- **Cost:** **$20 per month** (~1,050 EGP)
- **Usage:** Complementary tool to Claude for tasks where GPT performs better (fast research, certain types of analysis, cross-validation of solutions)

### 2.3 AWS Account with Open Company Card

- **Model:** A company-issued card linked to the AWS account, with monthly usage charged directly
- **Expected cost:** **$30 – $60 per month** (~1,560 – 3,120 EGP)
- **Expected breakdown:**
  - Small EC2 server — for development and staging
  - Small RDS database — managed database
  - EBS + S3 storage — for files and backups
  - Data transfer — network traffic

> **Important note:** AWS billing is variable based on usage. The number above is a realistic estimate for a small dev/staging environment. The bill will be monitored monthly with a transparent report shared with management.
