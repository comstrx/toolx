# ✨ Private Tools Ecosystem

## Overview

This is a focused ecosystem of 6 private tools designed to build, manage, automate, deploy, and scale modern software systems.

Together, they form a complete power layer for developers, teams, and companies that want to move faster, reduce repetitive work, and manage complex systems with clear automation.

---

## 1. rustx

### Rust Framework Foundation

`rustx` is a Rust workspace for building high-performance framework foundations, developer tooling, and infrastructure runtimes.

It is the long-term foundation for building powerful systems with Rust.

### Value

- Builds fast and safe backend systems
- Supports web, CLI, and app development
- Enables high-performance infrastructure tools
- Creates a future-ready framework foundation
- Combines Rust speed with developer productivity

---

## 2. panelx

### Admin Panel Compiler

`panelx` is an nextjs admin panel compiler for generating production-ready dashboards, CRUD systems, and business backoffices.

It aims to turn simple structured definitions into complete admin panels.

### Value

- Speeds up admin panel development
- Generates dashboards, forms, tables, and CRUD systems
- Supports business workflows
- Reduces repetitive frontend/backend admin work
- Helps companies build internal systems faster

---

## 3. bashx

### Bash Framework & Standard Library

`bashx` is a large cross-platform Bash framework with a full standard library.

It provides reusable building blocks for automation, scripting, system operations, and CLI tools.

### Value

- Creates reliable shell automation
- Standardizes Bash scripting
- Reduces fragile scripts
- Supports Linux, macOS, and cross-platform workflows
- Acts as the foundation for bigger tools

---

## 4. gunx

### Full Project Manager

`gunx` is an integrated project management CLI.

It helps create, run, test, build, clean, release, and manage projects across many technologies.

### Value

- One command system for many stacks
- Manages projects faster
- Detects project types
- Automates common development workflows
- Reduces setup time for teams and projects

---

## 5. infrax

### Infrastructure Blueprints

`infrax` is a collection of production-grade infrastructure blueprints.

It covers monoliths, Docker deployments, Kubernetes deployments, and microservices architectures.

### Value

- Provides ready infrastructure patterns
- Speeds up server and deployment setup
- Standardizes production environments
- Helps teams move from simple servers to scalable systems
- Documents real-world deployment knowledge

---

## 6. aliasx

### Quick CLI Life

`aliasx` is a fast command-line aliases framework for daily developer workflows.

It turns repeated terminal commands into short, memorable commands.

### Value

- Speeds up daily development
- Reduces command repetition
- Simplifies Git, GitHub, sync, deploy, and system tasks
- Makes developers faster inside the terminal
